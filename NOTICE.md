# Provenance and attribution

This project derives from [Likenttt/garmin-connect-plugin-for-dsh](https://github.com/Likenttt/garmin-connect-plugin-for-dsh), with the upstream history preserved. The original project targeted DeepSeek Harness. Its host-specific integration was removed in the standalone MCP refactor.

The upstream bundled skill credits 李二牛. That contribution is acknowledged here even though the skill has been rewritten as client-neutral guidance.

The original MIT license is retained without alteration in LICENSE. Dependencies retain their respective licenses. This is a community project, not an official Garmin product.

The unscoped npm package named garmin-connect-mcp is a separate project; this fork is distributed from https://github.com/xcbbc21/garmin-connect-mcp as source.
